Declare Siren apps, and watch and answer what Siren sends them.

USAGE
  siren <command> [flags]

GETTING STARTED
  signup              Make an organization on Siren
  login               Log in to Siren in your browser
  apps init           Write siren.app.json in this folder
  apps apply          Declare the app on Siren and save its key

APPS
  apps diff           Show what apply would change
  apps pull           Write siren.app.json from an app on Siren
  apps list           List the apps
  apps show           Show one app and its features
  apps scopes         List the scopes an app's key may hold
  apps events         List the events Siren can send an app
  apps rotate-key     Replace the app's key and revoke the old one
  apps rotate-secret  Replace the address's signing secret
  apps add-key        Make a key for an app that has none
  apps on             Turn the app on
  apps off            Turn the app off
  apps delete         Delete the app and revoke its key

REQUESTS
  apps requests       List what Siren sent, or show one request
  apps answer         Answer an ask by hand
  apps resend         Send a request again

DEVELOPER TOOLS
  listen              Send the app's requests to this machine
  trigger             Make test activity in a sandbox
  trigger ask         Send a feature a test ask
  logs tail           Watch requests, deliveries and API calls live
  simulate            Show what a scenario would make, writing nothing
  fixtures            Run a file of trigger steps
  apps test           Send the app's address a test delivery
  explain             Say why a sale paid what it did

SANDBOX
  sandbox create      Copy a live setup into a sandbox
  sandbox list        List your sandbox organizations
  sandbox reset       Clear activity, keep setup
  sandbox inbox       Read the sandbox's caught emails
  seed                Fill a sandbox with sample sales

RECIPES
  recipes preview     Show what a recipe would make
  recipes apply       Preview, ask, then apply a recipe
  recipes status      Show one recipe import
  recipes imports     List recent recipe imports
  recipes export      Print this organization's setup as a recipe
  recipes catalog     List ready-made recipes
  recipes show        Print one ready-made recipe
  recipes fetch       Print the recipe a Beacon handoff carries

CONDITION SETS
  condition-sets list        List the condition sets
  condition-sets get         Show one condition set
  condition-sets matches     Count and name who matches now
  condition-sets create      Make a condition set from JSON
  condition-sets conditions  List the conditions a set can use

ENROLLERS
  enrollers list      List the enrollers
  enrollers get       Show one enroller
  enrollers log       Show what an enroller did
  enrollers run       Run an enroller now
  enrollers create    Make an enroller from JSON

RECORDS
  <resource> <op>     List, get, create, update or delete a record
  get <path>          Read any route, such as get /programs
  post <path>         Write to any route, and put, patch and delete
  resources           List the resources and their operations
  open                Open a record's page in Siren's app

ACCOUNT
  logout              Log out, and forget the session here
  whoami              Show who you are logged in as
  orgs                List your organizations

FLAGS
  --sandbox           Use Siren's sandbox, whatever you logged in to last
  --live              Log in to or change a live organization
  --base-url <url>    Use another Siren, such as siren.example.com
  --org <slug>        The organization to act in, when you have several
  -q, --quiet         Skip the logo animation
  --verbose           Show the detail behind an error
  -h, --help          Show help for a command
  -v, --version       Show the version

ENVIRONMENT
  SIREN_BASE_URL      The Siren to use when no flag names one
  SIREN_ORG           The organization to act in, when no flag names one
  SIREN_TOKEN         A personal access token, for scripts and CI
  SIREN_APP_URL       Siren's app, for links, when it isn't beside the API
  SIREN_DEBUG=1       The same as --verbose
  NO_COLOR, CI        Plain output, and no logo animation

EXAMPLES
  $ siren login
  $ siren apps init
  $ siren apps apply

LEARN MORE
  Run siren <command> --help for a command's flags and examples.
  Read the guide at https://github.com/Novatorius/siren-node#command-line-tool
